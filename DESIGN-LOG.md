# Design Log

- Chose a lighthouse at the edge of a wide sea so the scene could read clearly with a small set of layered silhouettes.
- Kept a seven-role art palette (`sky`, `horizon`, `sea`, `cliff`, `stone`, `accent`, `shadow`); the Midnight theme replaces those roles without changing the shape rules.
- Used a clipped polygon for the distant shore and lighthouse silhouette, gradients for atmospheric depth and water, and pseudo-elements for the lantern bars and birds.
- Set the illustration width from one `--size` value and used percentages for internal placement so it scales as a single composition.
